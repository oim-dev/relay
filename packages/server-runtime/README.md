# @relay/server-runtime

Приватный пакет общей реализации Relay REST, OpenAPI, Swagger, SSE и опциональной
статики на NestJS/Fastify. Предметные операции выполняет Core; runtime выбирает
проект, проверяет транспортный ввод и доставляет результат.

- [Канонический REST-справочник](docs/API.md) — пользовательский контракт всех семейств.
- [Устройство и разработка](docs/DEVELOPMENT.md) — модули, контекст, события и проверки.
- [Запуск Server](../../apps/server/docs/USAGE.md) — для пользователя, без встраивания.
- [Общие границы компонентов](../../docs/ARCHITECTURE.md).

Корневой экспорт предоставляет `createServer(options)` без listener для встраивания
и inject-проверок и `startServer(options)` для запуска на `127.0.0.1` с `url` и `close()`.
Параметры передаёт вызывающее приложение; runtime не разбирает env и командную строку.
Без `webRoot` доступны API, SSE и Swagger, но не Web. MCP использует отдельно
запущенный Server, а не запускает этот runtime автоматически.
