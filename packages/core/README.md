# Core — предметное ядро Relay

`@relay/core` реализует всю предметную логику Relay: операции над знаниями и работой,
адресацию сущностей, прогресс, отношения, контекст и согласованное сохранение данных.
Local-клиент и Server вызывают одни прикладные сервисы. Ядро возвращает данные и ошибки,
но не HTTP-конверты, терминальное оформление или React-компоненты.

## Точки входа

- [Архитектура и расширение](docs/ARCHITECTURE.md) — слои, сервисы, путь операции,
  публичные импорты и добавление вида или действия.
- [Физическое хранение](docs/FORMAT.md) — версии и профиль модели данных, кодеки,
  индексы, WAL, конкуренция, явное обслуживание и миграции.
- [Разработка и проверки](docs/DEVELOPMENT.md) — команды из корня репозитория,
  выбор тестов по изменяемому механизму и добавление следующей миграции данных.

Предметные правила принадлежат [общему контракту](../../docs/domain/README.md),
покрытие интерфейсов — только [каталогу возможностей](../../docs/CAPABILITIES.md).
Переносимые схемы предоставляет [Contracts](../contracts/README.md).

Импортируйте модули через `@relay/core/*`, например
`@relay/core/application/entities/service` и `@relay/core/storage/workspace`.
У пакета нет корневого export. Условие `tasks-source` выбирает TypeScript-исходники;
обычный запуск использует собранный `dist`.
