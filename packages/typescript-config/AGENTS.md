# Работа с общей конфигурацией TypeScript

Инструкция для любого исполнителя и QA; общие правила — [AGENTS.md](../../AGENTS.md).

1. До изменения прочитайте [README](README.md) и контракт [base.json](base.json).
   Здесь только общая база компилятора; локальные пути и специальные настройки
   остаются у потребителей. Изменения вне пакета согласуйте с оркестратором.
2. Проверьте реальные `extends` и все затронутые наследующие конфигурации по
   [руководству](README.md#изменение-и-проверка). При влиянии на emit проверьте
   исполнение потребителей; собственных build/test здесь нет. Markdown-правка
   не требует полной сборки. Окружение описано в [scripts](../../scripts/README.md).
3. Не копируйте базу в приложения. Обновляйте знания по
   [DOCUMENTATION](../../docs/DOCUMENTATION.md); при неизвестных границах прочитайте
   [ARCHITECTURE](../../docs/ARCHITECTURE.md), не весь общий комплект документов.
