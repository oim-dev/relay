# Карта возможностей Relay

| Возможность            | Пользовательский результат                                       | Контракт                                                               |
| ---------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Продуктовая память     | Паспорт, фичи, сценарии, приложения, реализации и документы      | [Продукт](entities/product/README.md)                                  |
| Доски и задачи         | Постановка, канбан, декомпозиция и зависимости                   | [Доски](entities/boards/README.md), [канбан](entities/tasks/KANBAN.md) |
| Обсуждения задачи      | Полные сообщения людей и агентов                                 | [Обсуждения карточки](entities/tasks/KANBAN.md#обсуждения-и-история)   |
| Основные сущности      | Единые определения, ключи, ID и операции                         | [Движок](ENTITIES.md)                                                  |
| Связи                  | Направленные отношения, обратное чтение и объяснение контекста   | [Граф](RELATIONS.md)                                                   |
| Изолированные проекты  | Local/workspace, отдельные данные и подключения                  | [Проекты](entities/projects/README.md)                                 |
| Совместная работа      | Ревизии, сверка текущего состояния, SSE и сохранность черновиков | [Архитектура](../engineering/ARCHITECTURE.md)                          |
| Демонстрационная среда | Независимые проекты для текущего Relay                           | [Playground](applications/playground/README.md)                        |

[Планы работ](applications/web/PLANS.md) и [самостоятельные релизы](applications/web/RELEASES.md)
подключены к постоянным данным через Core/REST/CLI/MCP. Планы организуют этапы и задачи;
явный выпуск сохраняет статус, автора и дату, а состав и готовность остаются актуальными.
Этапы — вложенные записи плана. Обязательное основание исполнения задач —
отдельный следующий этап. Текущие проверки находятся в состоянии реализации.
Обзор представлен страницей «В разработке». Общая история проекта удалена вместе с аудитом.
Прежняя доска, прежний паспорт, требования/знания и работа/проверки удалены вместе
с прежними API/CLI/MCP-операциями. Документы, комментарии, алиасы и предметные сведения
планирования сохраняются как текущие данные; общий и встроенный автоматический audit,
события, квитанции и результаты команд запрещены.

[Состояние реализации](../engineering/implementation/README.md), [направление](DIRECTION.md).
