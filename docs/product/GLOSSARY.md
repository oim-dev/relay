# Термины Relay

| Термин                     | Смысл и граница                                                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Relay                      | Сам продукт: память проекта и сопровождение его жизненного цикла                                                                |
| Проект Relay               | Изолированная область конфигурации, продукта, задач и истории                                                                   |
| Workspace                  | Реестр независимых проектов, а не общий продукт или общая база задач                                                            |
| Продукт пользователя       | Описание того, что создают в проекте Relay                                                                                      |
| Паспорт                    | Назначение, пользователи, границы и описание продукта                                                                           |
| Возможность, фича          | Устойчивая часть поведения; не задача на её реализацию                                                                          |
| Сценарий                   | Действие и наблюдаемый результат внутри одной фичи                                                                              |
| Приложение продукта        | Логическая программная часть пользовательского продукта; не регистрация проекта                                                 |
| Приложение Relay           | CLI, Server, Web, MCP или Playground в этом репозитории                                                                         |
| Вклад, контракт реализации | Ответственность одного приложения за фичу или сценарий, с собственным описанием и состоянием                                    |
| Документ продукта          | Самостоятельный материал пользовательской библиотеки, связанный с продуктовыми областями                                        |
| Линк                       | Продуктовые данные об отношении сущностей у владельца; нужны UI и продуктовым правилам                                          |
| Связь                      | Отдельно сохраняемое отношение движка Core для контекста; явно устанавливается/разрывается бекендом после продуктового действия |
| Контекст сущности          | Публичное чтение окружения по связям с объяснениями и границами; не устанавливает отношения                                     |
| План                       | Самостоятельный план работ с целью и упорядоченным массивом этапов                                                              |
| Этап                       | Вложенная запись плана с локальным ID, результатом и явно выбранными задачами; не отдельная сущность                            |
| Задача                     | Конкретное поручение исполнителю; иерархия задач и зависимости имеют разный смысл                                               |
| Исполнение                 | Одна попытка выполнения; не доказательство завершения задачи                                                                    |
| Проверка                   | Наблюдаемый результат сценария или команды с версией и окружением                                                               |
| Приёмка                    | Заключение о выполнении критериев на основании проверок                                                                         |
| Релиз                      | Самостоятельная запись с планами состава, реквизитами, статусом, датой и автором выпуска; содержание планов читается актуальным |
| Установка                  | Факт поставки в окружение; запись не выполняет развёртывание                                                                    |
| Контрольная точка          | Сохранённое состояние для продолжения и сверки изменений                                                                        |

Спецификации: [продукт](entities/product/README.md), [задачи](entities/tasks/README.md).
Термины «линк» и «связь» зарезервированы и не взаимозаменяемы. Правила использования:
[обязательный стандарт линков, связей и контекста](../development/LINKS-AND-CONTEXT.md).
[Планы](../reference/PLANNING.md) и [релизы](../reference/RELEASES.md) имеют действующие
предметные операции. Исполнения, приёмки и установки обозначают понятия процесса;
прежние структурированные записи этих областей удалены.
