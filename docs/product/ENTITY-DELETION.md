# Удаление сущностей

Удаление — явное действие оператора над сохранённой сущностью. Перед подтверждением
показываются полный состав каскада и сохраняемые сущности, у которых снимаются ссылки.

| Выбранная сущность  | Удаляется вместе с ней                                      | Сохраняется                                                     |
| ------------------- | ----------------------------------------------------------- | --------------------------------------------------------------- |
| Фича                | Её сценарии и реализации фичи/сценариев во всех приложениях | Приложения, их доски, задачи и документы                        |
| Сценарий            | Его реализации во всех приложениях                          | Фича, приложения, задачи и документы                            |
| Приложение          | Его реализации, доска и все задачи на ней                   | Общие фичи/сценарии, другие доски и их задачи, документы        |
| Реализация фичи     | Реализации сценариев этой фичи в том же приложении          | Общее требование, приложение и задачи                           |
| Реализация сценария | Только выбранная реализация                                 | Сценарий и остальные реализации                                 |
| Задача              | Карточка с критериями, обсуждениями и её лентой             | Подзадачи и другие задачи; родительство и зависимости снимаются |
| Документ            | Только документ                                             | Все сущности, к которым он был прикреплён                       |

Активные связи графа с любым удаляемым концом отзываются. Предметные ссылки внешних
задач и документов очищаются. Исторические события оставшихся сущностей и графа
сохраняют прежние значения: они описывают прошлое, а не действующие связи.
Проект, паспорт продукта и самостоятельное удаление системных досок не входят в сценарий.

Подтверждение проверяет версию просмотренного состояния. Новая запись, изменение связей
или обсуждений требует обновить предпросмотр. Ошибка не означает успех; повтор после
неопределённого сетевого результата использует тот же requestId и возвращает квитанцию.
Состав не обрезается: при более чем 1000 удаляемых или 1000 сохраняемых затронутых
сущностей операция требует сначала удалить дочерние записи отдельно.

Удаление постоянно; интерфейс восстановления не предусмотрен. Хранилище обязано
восстановить незавершённую составную операцию до следующего чтения.
Удалённые ключи и алиасы не выдаются новым сущностям: прежняя ссылка не должна
начать открывать другую запись. Новый объект получает новый ключ.
