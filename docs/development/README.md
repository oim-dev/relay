# Разработка Relay

Главный агент работает по [профилю оркестратора](../../packages/dev-agents/src/orchestrator.md),
исполнители — по собственным самодостаточным профилям. [Корневой AGENTS.md](../../AGENTS.md)
содержит общие правила для всех. Материалы этого раздела выбираются по предмету задачи;
они не являются обязательным пакетом чтения для запуска роли.

- [Команда агентов](AGENT-TEAM.md) — владельцы, передача работы, контракты и приёмка.
- [Пакет агентов разработки](../../packages/dev-agents/README.md) — профили и сборка OpenCode, Claude Code, Codex.
- [Порядок разработки](PROTOCOL.md) — постановка, проверка и передача результата.
- [Правила документации](DOCUMENTATION.md) — владельцы фактов, достоверность и навигация.
- [Линки, связи и контекст](LINKS-AND-CONTEXT.md) — предметные отношения и чтение графа.
- [Стандарт интерфейсов](INTERFACE-STANDARD.md) — тексты, CLI, MCP и человеческие сценарии.
- [Окружение и команды](../DEVELOPMENT.md) — зависимости, запуск и проверки.
- [Расширение](EXTENDING.md) — добавление операций и команд.
- [Скиллы](SKILLS.md) — установка, исходники, сборка и проверка продуктового скилла.
- [Пакет продуктового скилла](../../packages/relay-skill/README.md) — инструкции для пользователей Relay и их сборщик.
- [Выпуск](RELEASING.md) — пакеты и релизный процесс.

[Техническая библиотека](../engineering/README.md) связывает приложения и пакеты
с их реализацией. Документация обновляется по смысловым изменениям публичного поведения.
Постоянные журналы агентов, рабочие досье и индекс работ не ведутся.
