# Работа с агентами

Руководство для пользователей Relay. Разработка самого репозитория организована
отдельной [командой](../development/AGENT-TEAM.md) и не требует постоянных Markdown-журналов.

Все участники используют выбранную общую базу. Оркестратор передаёт исполнителю
проект, ключ/ID задачи, actor, подключение, рабочий каталог и критерии результата.
В workspace каждый вызов указывает project. CLI в local работает через Core либо HTTP;
MCP всегда подключается к Relay Server. [Настройки](../reference/CONFIGURATION.md).

Начните с `entity_types`, `entities_list`, `entity_get`, `entity_context`;
CLI-аналоги — `entities types/list/get` и `graph context`. Требования хранятся в продукте,
работа — на досках, дополнительные материалы — в документах и графе.

Исполнитель сохраняет фактический результат и продолжение в Markdown, не выдумывает
проверки и не выдаёт прежнее подтверждение за свежее. Оркестратор проверяет общий результат.
Авторы, ревизии и requestId обязательны для совместных записей; после записи перечитайте данные.

Процессы агентов, Git, тесты и поставка выполняются внешней средой в рамках поручения.
Relay хранит контекст, но сам не запускает исполнителей.
