# Работа с задачей

1. Выберите проект и доску через `projects list` и `boards`.
2. Создайте задачу: `task create --board product --title "Проверить сценарий" --actor human`.
3. Сохраните Markdown-постановку, продуктовые цели и реальные зависимости.
4. Прочитайте задачу и связи через `task get <key>` и `task links <key>`.
5. Выполните поручение внешними инструментами; сохраните результат, фактические проверки,
   ограничения и следующий шаг в описании задачи либо связанном документе.
6. Измените колонку через `task move <key> --column review --if-revision <n> --actor <actor>`.
   Приёмка участником и готовность продукта не выводятся автоматически из статуса задачи.

Для изменения нужна актуальная ревизия. `--request-id` служит корреляции, не дедупликации.
После потери ответа или конфликта перечитайте состояние и согласуйте необходимое изменение.
Родительство задаёт декомпозицию; зависимости — порядок. Отмена не удовлетворяет зависимость.
