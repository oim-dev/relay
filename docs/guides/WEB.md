# Работа в Web

Запустите Relay Server и откройте его адрес. В workspace выберите проект;
в local откроется единственный проект. Все страницы и черновики сохраняют эту область.

## Продукт

В сайдбаре раскройте «Продукт»: паспорт, возможности, приложения, документы.
Опишите цель и требования в Markdown. Сценарий принадлежит фиче; приложение выбирает
общие требования и описывает свой вклад. Готовность общих требований вычисляется
по актуальным реализациям. Документы имеют самостоятельное содержание и связи с областями.
[Подробный контракт](../product/applications/web/PRODUCT.md).

## Доски и задачи

Выберите продуктовую, прикладную или инфраструктурную доску. «Создать задачу» сразу
сохраняет пустую карточку и открывает центральное окно. Заполните заголовок и Markdown,
выберите продуктовые цели, добавьте связи с существующими задачами.

Статус и доска меняются компактными меню; перенос доступен мышью и клавиатурой.
ID остаётся постоянным, ключ меняется при смене доски. Колонки читаются порциями по 40.
Поиск и фильтры сохраняются в URL. Только done выполняет зависимость, отмена — нет.
Закрытие окна сохраняет черновик. Ошибка записи не стирает ввод, конфликт требует решения.
[Канбан](../product/entities/tasks/KANBAN.md).

## Связи и настройки

«Связи проекта» показывает каталог и отношения. Выберите корень, глубину и профиль;
пути объясняют контекст. Явные связи можно добавлять и отзывать, предметные проекции
изменяются у владельцев. Поиск и списки имеют продолжение.

Шестерёнка открывает настройки имени и slug. Сохранение обновляет адрес без смены ID.
SSE сообщает об изменениях; после восстановления связи данные перечитываются.

## Разделы в разработке

Обзор показывает «В разработке»; общий аудит и раздел истории удалены. Прежняя доска и скрытые
страницы удалены. Неизвестный адрес показывает «Страница не найдена».
