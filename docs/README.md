**основания технических решений**.

## Актуальность

Действующие документы относятся к исходникам выбранной ветки. Состояние реализации
указывает основание сверки; исторические отчёты не подтверждают текущее окружение.
Предложения не становятся реализованными функциями по наличию документа.

Документы обновляются при смысловом изменении публичного поведения, контрактов и процессов.
Постоянные журналы агентов и рабочие досье не ведутся.
Результат исполнителя передаётся оркестратору в ответе.
[Порядок разработки](development/PROTOCOL.md) описывает передачу результата,
[правила библиотеки](development/DOCUMENTATION.md) — владельцев информации.
`pnpm run docs:check` проверяет ссылки и якоря, но не истинность содержания.
