# Идентичность продукта и самостоятельные реализации

Принято пользователем 20 сентября 2026 года.

Часть решения о сохранении истории и квитанций **заменена**
[контрактом без истории операций](../../reference/STORAGE.md). Ниже сохранено
происхождение решения; идентичность и текущий состав не требуют журнала операций.

## Причина

Читаемые номера нужны человеку и агенту в Web/API/CLI/MCP. Однако совпадение номера
после объединения данных не означает совпадение сущностей. Хранение целого состава
приложения в одном JSON также связывает ревизии независимых вкладов и увеличивает
ответы при выборе цели задачи.

## Решение

- ID определяет идентичность, физический путь и сохранённые связи. Ключ хранится
  отдельно и разрешается в ID на входе общей бизнес-операции.
- FEATURE/SCENARIO нумеруются в пределах проекта. PREFIX-FI/SI первоначально наследует
  номер требования, но затем хранится независимо и не пересчитывается при чтении.
- Коллизия ключа не запрещает чтение по ID. Обращение по неоднозначному ключу возвращает
  ошибку с кандидатами; исправление ключа не переписывает ссылки.
- Приложение хранится в applications/<ID>/application.json, каждый вклад — отдельным
  ID-файлом внутри features/scenarios. scope.json сохраняет историю/квитанции прежнего
  агрегата; список состава строится из файлов, чтобы устаревший манифест после слияния
  не скрывал сохранённую реализацию.
- Независимая правка проверяет ревизию реализации; массовая замена состава проверяет
  общую версию и публикуется возобновляемой операцией под блокировкой.
- Списки для связей используют краткий восстанавливаемый индекс; подробности — адресное
  чтение. Индекс не является источником содержания.

## Последствия

Новая запись использует v3, старые v1/v2 читаются. Незавершённая публикация восстанавливается
по долговечному намерению; несовместимая внешняя правка блокирует восстановление вместо
перезаписи. Старые клиенты не должны параллельно писать после перехода на новый формат.
Общие редакторы всего состава по-прежнему могут получать полный снимок; адресные
интерфейсы не зависят от его размера. Точный контракт — в [справочнике продукта](../../reference/PRODUCT.md).
