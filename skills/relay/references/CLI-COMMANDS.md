# Команды Relay CLI

Справочник сформирован из зарегистрированных команд. Порядок работы и примеры — в [главном руководстве](../SKILL.md) и [сценариях](EXAMPLES.md).

`relay-cli` означает установленную команду или `npx @oim-dev/relay-cli`. В workspace указывайте проект префиксом либо `--project`. Конкретный help: `relay-cli <команда> --help`.

## Общие параметры

| Параметр              | Назначение                                                                     |
| --------------------- | ------------------------------------------------------------------------------ |
| `-V, --version`       | Показать версию CLI                                                            |
| `--config <path>`     | Путь к .relay/config.json или relay.workspace.json; приоритет над RELAY_CONFIG |
| `--project <name>`    | Имя проекта из workspace; также relay-cli <проект> <команда>                   |
| `--server-url <url>`  | Адрес сервера; приоритет над RELAY_SERVER_URL и server.url                     |
| `--local`             | Работать напрямую с локальным Core, игнорируя HTTP-настройки                   |
| `--actor <id>`        | Автор записи, например human; приоритет над RELAY_ACTOR                        |
| `--format <format>`   | Формат ответа Значения: json, text.                                            |
| `--color <mode>`      | Цветовая подсветка (по умолчанию auto) Значения: auto, always, never.          |
| `--max-bytes <bytes>` | Максимальный размер ответа UTF-8                                               |

**Синтаксис:** `relay-cli projects add [options] <name> [path]`.

Прочитать прогресс фичи

| Аргумент | Назначение                                        |
| -------- | ------------------------------------------------- |
| `ref`    | Ключ, ID или kind:ID сущности в выбранном проекте |

| Параметр                       | Назначение                                                                   |
| ------------------------------ | ---------------------------------------------------------------------------- |
| `--offset <n>`                 | Смещение каждого списка                                                      |
| `--limit <n>`                  | Размер страницы: 20 по умолчанию, максимум 100                               |
| `--snapshot-version <version>` | Версия первой страницы; обязательна при offset > 0; отличается от версии CLI |

| `--clear-scope`                | Явно очистить область изменения                    |
| `--participants <actors...>`   | Участники плана                                    |
