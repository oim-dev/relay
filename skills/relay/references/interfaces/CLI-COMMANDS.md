# Команды Relay CLI

Справочник сформирован из зарегистрированных команд. Порядок работы — в [главном руководстве](../../SKILL.md), семантика — в [CLI](CLI.md), примеры — в [сценариях](../agent/EXAMPLES.md).

Запускайте только через `npx @oim-dev/relay-cli`. В workspace указывайте проект префиксом либо `--project`. Конкретный help: `npx @oim-dev/relay-cli <команда> --help`.

## Общие параметры

| Параметр             | Назначение                                                                     |
| -------------------- | ------------------------------------------------------------------------------ |
| `-V, --version`      | Показать версию CLI                                                            |
| `--config <path>`    | Путь к .relay/config.json или relay.workspace.json; приоритет над RELAY_CONFIG |
| `--project <name>`   | Имя проекта из workspace; также npx @oim-dev/relay-cli <проект> <команда>      |
| `--server-url <url>` | Адрес сервера; приоритет над RELAY_SERVER_URL и server.url                     |
| `--local`            | Работать напрямую с локальным Core, игнорируя HTTP-настройки                   |
| `--actor <id>`       | Автор записи, например human; приоритет над RELAY_ACTOR                        |
| `--format <format>`  | Формат ответа Значения: json, text.                                            |

## inspect graph list

**Синтаксис:** `npx @oim-dev/relay-cli inspect graph list [options]`.

Прочитать граф или выбранный подграф с продолжением

| Параметр                  | Назначение                                             |
| ------------------------- | ------------------------------------------------------ |
| `--root <address>`        | Ключ или ID корня; без него весь проект                |
| `--type <type>`           | Фильтр типа отношений                                  |
| `--direction <direction>` | both, outgoing или incoming                            |
| `--profile <profile>`     | all — полный обход; context — совместимое имя all      |
| `--depth <n>`             | Глубина обхода 0–100                                   |
| `--q <text>`              | Поиск сущностей по ключу, адресу и названию            |
| `--limit <count>`         | Размер страницы, от 1 до 100                           |
| `--cursor <cursor>`       | Курсор из предыдущего ответа; фильтры должны совпадать |
