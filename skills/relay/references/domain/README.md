## Как читать

Для конкретного действия достаточно правил его области и затронутого общего механизма.
Например, работа с планом требует понимания его состава; объяснение неготовности —
правил прогресса; конфликт записи — правил сохранения данных.

Синтаксис команд, аргументы инструментов и поля HTTP-запросов принадлежат справочникам
интерфейсов. Внутреннее устройство файлов, сервисов и адаптеров — документации пакетов.
Эти детали не создают независимых вариантов предметных правил.

Практическое применение: [рабочий процесс](../guides/WORKFLOW.md),
[содержание записей](../guides/CONTENT.md), [восстановление после ошибки](../guides/RECOVERY.md).
