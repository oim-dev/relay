# Работа с инструментами репозитория

Применяй корневой `AGENTS.md`; если он не передан средой, прочитай его.
Начинай с [README](README.md), а для выпуска — с [процесса выпуска](release/README.md).

- Проверяй фактический вход команды в `package.json` и вызываемый скрипт.
  Не переноси старые версии инструментов и разовые обстоятельства прежнего выпуска
  в обязательные правила. Зависимости, scripts и конфигурации проверяй на потребителях.
- Исправляй источник или механизм генерации, не готовый результат. Назначение одного
  писателя общих выходов согласуй через оркестратора; запускай генерацию после готовности
  входов. Проверяй детерминизм, обнаружение drift и сохранение чужих файлов.
- Сохраняй пользовательские базы, процессы, порты и настройки. Для проверки записи
  используй изолированные ресурсы; освобождай только свои. Смена cwd сама по себе
  не изолирует скрипт с путями, привязанными к его расположению.
- Сборка, упаковка, независимая установка и публикация — разные действия.
  Не запускай публикацию, push или создание релиза без отдельного разрешения;
  правила корневого `AGENTS.md` действуют и для автоматизирующих скриптов.
- Проверяй реальные аргументы, cwd/INIT_CWD, ошибки и завершение дочерних процессов.
  Выбирай проверки по изменённому механизму, а не запускай весь выпуск для правки текста.
  В результате укажи точные входы, артефакты, команды, ограничения и оставшиеся ресурсы.
