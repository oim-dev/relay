# Relay Web

Браузерный интерфейс человека к общей памяти проекта Relay: продуктовым знаниям,
документам, задачам, планам и релизам. Web обращается к Relay Server через REST;
данные общие с CLI и MCP, предметные правила принадлежат Core.

Собранная SPA входит в поставку [Server](../server/README.md). Для обычной работы
откройте адрес запущенного сервера; отдельный Vite нужен только разработчику.
В local открывается один проект, в workspace пользователь выбирает проект.
Основной адрес — `/projects/:project`, где `:project` — slug.

Из каталога уже инициализированного проекта или workspace:

```bash
npx @oim-dev/relay-server
```

Откройте адрес, напечатанный сервером. Первое подключение описано в
[начале работы](../../docs/guides/GETTING_STARTED.md).

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

Web доступен на `http://127.0.0.1:5173`. По умолчанию сервер использует playground
workspace, поэтому перед изменением данных выберите собственную конфигурацию,
как описано в [разработке](docs/DEVELOPMENT.md#запуск-на-своих-данных).
