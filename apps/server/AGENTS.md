# Работа в приложении Server

Инструкция для любого исполнителя и QA в `apps/server`; общие правила —
[корневой AGENTS.md](../../AGENTS.md). Здесь команда запуска и поставка Web,
не HTTP-реализация. Выходящие за владельца изменения согласуйте с оркестратором.

## Маршрут чтения

- До изменения прочитайте [README](README.md), контракт запуска [USAGE](docs/USAGE.md)
  и [DEVELOPMENT](docs/DEVELOPMENT.md).
- При неизвестном контексте прочитайте [PRODUCT](../../docs/PRODUCT.md) и
  [ARCHITECTURE](../../docs/ARCHITECTURE.md), затем только затронутую
  [возможность](../../docs/CAPABILITIES.md) и [предметный контракт](../../docs/domain/README.md).
  Вся общая библиотека не является обязательным вводным пакетом.
- При изменении подключения сверьте [CONFIGURATION](../../packages/project-runtime/docs/CONFIGURATION.md),
  при затрагивании HTTP — [API runtime](../../packages/server-runtime/docs/API.md).

## Границы приложения

- Сохраняйте здесь env/flags, передачу явных параметров runtime, вывод URL/PID,
  открытие браузера, сигналы остановки и доставку assets. Не копируйте Core/HTTP.
- Различайте настроенный URL клиента и фактический listener; не зашивайте личную
  базу или dev-пути в поставку. Запуск не создаёт базу и не выполняет скрытое обслуживание.
- Общие гарантии записи и актуального хранения берите из
  [STORAGE](../../docs/domain/STORAGE.md), не дублируйте версии или старые обещания replay.
  Не добавляйте автоматический retry мутации при ошибке запуска/подключения.
- При API-клиенте/codegen-логике загрузите `rest-api-codegen-ru` через skill tool;
  изменения OpenAPI/генерации направляйте владельцам, generated SDK не правьте.
  Внешние инструменты применяйте только по фактической необходимости.

## Проверки и документация

- Выбирайте из DEVELOPMENT: `pnpm --filter @oim-dev/relay-server run typecheck`,
  `pnpm run test:server`; при изменении поставки — `pnpm run package:check:server`.
  Подготовка сборки описана там же; собственного lint нет.
- Для lifecycle проверяйте фактический URL, оба формата вывода и завершение ресурсов;
  для поставки — установленный архив, Web/assets и SPA/API, не только checkout.
- Следуйте [DOCUMENTATION](../../docs/DOCUMENTATION.md): README поставляется отдельно
  от локальных docs. Для правки текста используйте адресные проверки без запуска сервера.
